# Portal Turístico — Descubra o Brasil

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como atividade avaliativa da disciplina de Desenvolvimento Web. O objetivo foi criar um site turístico apresentando destinos do Brasil, cultura e gastronomia, utilizando HTML e CSS.

O site foi criado para uma agência fictícia chamada Brasil Encantado, com foco em navegação simples e layout organizado.
